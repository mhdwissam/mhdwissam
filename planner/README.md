# مخطِّط الدراسة — بروفيسور ميدكس (النسخة الأولى)

نموذج أولي يعمل بالمتصفح للرحلة الأساسية كاملة (الخطوات 1–9 من وثيقة المواصفات).
البيانات محفوظة بالمتصفح (localStorage) مع بيانات تجريبية. الربط مع Supabase مؤجَّل للمرحلة القادمة.

## التشغيل
```bash
cd planner
npm install
npm run dev     # http://localhost:5173
npm test        # اختبارات قواعد الحساب
npm run build   # ملفات ثابتة في dist/
```

## حسابات تجريبية
| الدور | الموبايل | كلمة السر |
|---|---|---|
| طالب | 0933123456 | 123456 |
| المدير | 0999000000 | admin123 |

## الشاشات
- **الطالب:** دخول، حساب جديد، الرئيسية (مطلوب اليوم، الوضع لكل مادة، الأيام السبعة الجاية)، خطتي (التواريخ، الدراسة السابقة، الأيام)، المادة (الفصول والمهام، خلصت/تراجع، نتائج الدورات)، الترتيب، الإشعارات.
- **المدير:** المحتوى (مواد، فصول، مهام، أيام مقترحة، الإظهار)، التقويم والامتحانات، الطلاب الضعاف وإرسال العروض.

## شريط التجربة
الشريط الأصفر أعلى الشاشة يغيّر «تاريخ اليوم» لتجربة إعادة الحساب اليومي، وأسبوع المراجعة، ورسالة ما بعد الامتحان، ويعيد البيانات التجريبية لحالتها الأولى. هذا الشريط للتجربة فقط وليس جزءاً من المنتج.

## الملفات
- `src/lib/engine.js` — كل قواعد الحساب (الساعات، الوضع، حالة الفصل، الترتيب، الطلاب الضعاف).
- `src/lib/actions.js` — العمليات والصلاحيات.
- `src/lib/seed.js` — البيانات التجريبية (الفصول توضيحية حتى يُدخل ملف أوقات المدربين).
